# Carpe science

Время ловить науку и расширять горизонты. Расписание научных лекций, фестивалей и школ по всей России.

## Что где лежит

- `public/index.html` — сайт.
- `public/admin.html` — страница админа (`/admin`): статистика, заявки организаторов, скрытие событий.
- `server/server.py` — сервер: отдаёт сайт, принимает заявки, считает посещения и отметки «был(а) здесь». Только стандартная библиотека Python, база SQLite.
- `data/events.json` — события, которые находит ежедневный сборщик. Его обновляет задача по расписанию в Claude.
- `deploy/install.sh` — установка на VPS. `deploy/update.sh` — забирает обновления из GitHub каждые 10 минут.

## Где хранятся данные

- События сборщика — в этом репозитории, в `data/events.json`.
- Заявки организаторов, одобренные события, скрытые события, статистика и отметки — на сервере, в `/var/lib/carpe/carpe.db`. Их нет в GitHub.
- Пароль админа и секретный ключ — на сервере, в `/etc/carpe/env`. Их нет в GitHub.

## Статистика без слежки

Сайт не ставит cookie посетителям и не хранит IP-адреса. Посетитель за день считается по необратимому хешу от адреса и браузера, который меняется каждые сутки. Поэтому баннер о cookie не нужен.

## Полезные команды на сервере

```
systemctl status carpe          # работает ли сайт
journalctl -u carpe -n 50       # последние сообщения сервера
bash /opt/carpe/deploy/update.sh   # забрать обновления прямо сейчас
nano /etc/carpe/env && systemctl restart carpe   # сменить пароль админа
```

## Резервные копии

Каждую ночь в 4:00 база копируется в `/var/backups/carpe/`, копии хранятся 14 дней. Сделать копию вручную:

```
sqlite3 /var/lib/carpe/carpe.db ".backup '/root/carpe-backup.db'"
```
